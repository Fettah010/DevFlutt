## 7. Security, privacy, dependencies, licenses

No live provider projects or production credentials were used. Firebase/Supabase data
contracts are fake-backed; server authorization, Firestore Rules, and Supabase row-level
security remain provider-owner responsibilities. The optional-module dependency union now
includes the provider packages, and the 173-package license inventory is current. The local
V2 Gitleaks scan found no leaks in history or the worktree; OSV-Scanner reported no
vulnerable packages. Exact-candidate CI passed. The temporary self-test PR's separate Patrol
workflow failed with `No space left on device` while building; the candidate Patrol workflow
passed in run `41295779804`.

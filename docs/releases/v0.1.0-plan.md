## 6. Design / architecture

Blank-first minimal app. No state management, no routing, no networking.

```
lib/
  main.dart                     # entry point
  app.dart                      # MaterialApp root
  core/
    config/app_config.dart      # typed config boundary (env-driven, validated)
    theme/app_theme.dart        # minimal light/dark theme tokens
  features/home/home_page.dart  # single example screen
test/
  unit/app_config_test.dart
  widget/home_page_test.dart
```

**Dependencies:** Only `flutter` SDK + `cupertino_icons`. Dev: `flutter_test`, `flutter_lints`.

**Android config:** AGP 9.0.x, Gradle 9.x, Kotlin 2.2.x, compileSdk 36, minSdk 24, targetSdk 36, JDK 17. Conservative flags: `android.builtInKotlin=false`, `android.newDsl=false`.

## 15. Risks and mitigations; rollback/recovery

| Risk | Mitigation |
|---|---|
| Flutter 3.47 template AGP 9 + built-in Kotlin incompatibility | Set `android.builtInKotlin=false` + `android.newDsl=false` (conservative path) |
| CI runner Flutter version drift | Pin Flutter version in CI workflow (`subosito/flutter-action` with version) |
| Local inability to run Flutter commands | All Flutter gates route to CI; local work limited to file authoring + static checks |
| Rollback | Git history is append-only; revert by resetting branch |

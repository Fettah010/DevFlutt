## 1. Delivered outcome

- Replaced placeholder Patrol checks with a real app smoke test and lifecycle, system-theme,
  and Wi-Fi-disabled tests. Removed permission checks that asserted behavior the app did not
  implement.
- Added Android instrumentation host setup and enabled Patrol build-time test discovery.
  This fixed the prior zero-test Gradle report.
- Added a device-aware local runner that waits for boot, records tool and device versions,
  applies timeouts, rejects zero/missing/failed/skipped summaries, and retains failure logcat.
- Replaced the synthetic `Hello Patrol`/failure-suppressed matrix with a pinned emulator CI
  workflow that runs smoke and regression suites and uploads reports and diagnostics.
- Documented supported coverage and deferred generated-project UI testing until it can run
  the generated app entry point.

## 4. Disclosures and deferred work

- This evidence covers an Android emulator, not a physical device or iOS.
- The Wi-Fi case verifies the blank app renders without Wi-Fi. It does not test an offline
  data layer or synchronization.
- The blank app has no permission flow, so no permission UI test is claimed.
- Patrol coverage of generated projects is deferred to v0.10.0, when a real generated-app
  harness can be validated.
- The former Patrol matrix tested a synthetic widget and swallowed command failures; it was
  removed rather than counted as coverage.

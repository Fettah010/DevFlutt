## 3. Research and ADR decisions (incl. rejected alternatives)

See [`docs/research/v0.8-android-platform-services.md`](../research/v0.8-android-platform-services.md).
No new ADR was needed. Package source inspection confirmed Workmanager's Boolean-only
success/retry result. Inspection of `workmanager_android`'s manifest found it also declares
`POST_NOTIFICATIONS` and foreground-service permissions; the generated adapter does not
expose foreground work, so those unused declarations are removed by manifest merge unless
the local-notifications module is selected. WorkManager's boot, wake-lock, and network-state
permissions are declared and reported.

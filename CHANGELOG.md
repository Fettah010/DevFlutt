## [0.1.0] - 2026-10-18

### Added

- Blank Flutter Android starter app with minimal theme tokens and one example screen.
- Typed configuration boundary with environment-driven values and validation.
- Strict static analysis (`flutter_lints`) and unit/widget test examples.
- GitHub Actions CI: format, analyze, test, and Android debug build smoke.
- Repository documentation: README, CONTRIBUTING, SECURITY, AGENTS.md, CHANGELOG.
- `tool/verify` scripts (Windows PowerShell and POSIX bash) for local quality gates.
